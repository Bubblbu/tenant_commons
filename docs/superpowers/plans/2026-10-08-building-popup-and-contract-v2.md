# Building Popup & Export Contract v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat, sentinel-laden building export with a typed, validated contract built on parties-in-roles, and rebuild the building popup as a three-tab view (Summary / Ownership chain / Building) on top of it.

**Architecture:** `reconstruct_points()` keeps producing the internal polars frame (it also feeds markers, blocks and filter config). New pure modules turn each row into Pydantic `Building` records (`export_parties.py`, `export_contract.py`) and a `networks.json`; the Pydantic models (`contract.py`) are the public allowlist and emit a JSON Schema from which the frontend's TypeScript types are generated. The frontend keeps a flat view model (`flat.ts`) for tables/picker/indexes/coverage/CSV and renders the popup from the nested `Building`.

**Tech Stack:** Python 3.12, polars 2, pydantic 2, pytest (`uv run pytest`); TypeScript, Vite, vitest (`npm test` in `frontend/`), json-schema-to-typescript.

**Spec:** `docs/superpowers/specs/2026-10-08-building-popup-and-contract-v2-design.md`

## Global Constraints

- `schema_version` is `2` on every artifact; the frontend's `EXPECTED_SCHEMA_VERSION` is `2`. No v1 compatibility.
- Every public model uses `extra="forbid"`; no string field may be `"(Unknown)"`, `"unknown"`, `""` or whitespace-only — missing is `null`.
- Dates are ISO `YYYY-MM-DD` strings.
- Public provenance is source *types* only; every non-registry claim source appears as `vtu_research`; `ownership_claims.source_note` never leaves the database.
- Interest holders carry name, interest type and PIDs only — never LOTR residence, citizenship or registered-address fields.
- No unconfirmed claims network in public output.
- `value_bldg = 1` is a valid assessed value.
- Popup width ≤ 300px (Leaflet `maxWidth: 320` incl. padding).
- Git: the user approves git actions. Each task's commit step is a *proposed* commit — ask before running it. Never add Claude attribution to commits.
- Never commit anything under `data/` (gitignored) or raw membership CSVs.

## Review Focus

1. **Overlay records** (SRO/co-op points that matched no building: no units, year, value or owner) must render all three popup tabs without errors and with "Not on record" — pinned in Task 11 and Task 13 tests.
2. **A building with both a registry filing and an SRO-inventory owner**: the registry owner wins; the SRO owner must not appear as a second owner — pinned in Task 5.
3. **Assessed values missing on one side, or summing to 0**: `value` is `null` and no bar renders — pinned in Task 6 and Task 13.
4. **Hostile text in any party/network/building name** (`<img onerror>`): escaped everywhere in the new popup modules — pinned in Task 11/12/13 tests.
5. **Tab memory across different buildings**: opening Ownership on one popup then opening another building opens on Ownership; a reload starts on Summary — pinned in Task 11.

```python
"""Public export contract v2 (spec 2026-10-08-building-popup-and-contract-v2-design.md).

These models are the allowlist of what reaches the public artifacts:
`extra="forbid"` means a field reaches building_records.json/networks.json
only by being declared here, so a sensitive column can't leak by being
added to a dataframe. Missing values are null — never a sentinel string.
"""

from __future__ import annotations

from typing import Annotated, Literal

from pydantic import AfterValidator, BaseModel, ConfigDict, Field, Strict

SCHEMA_VERSION = 2

_SENTINELS = {"(unknown)", "unknown"}


def _no_sentinel(value: str) -> str:
    if not value.strip() or value.strip().lower() in _SENTINELS:
        raise ValueError(f"missing values are null, not {value!r}")
    return value


Text = Annotated[str, AfterValidator(_no_sentinel)]
IsoDate = Annotated[str, Field(pattern=r"^\d{4}-\d{2}-\d{2}$")]
# Strict: a float year (1970.0) or a numeric string fails instead of being coerced.
Int = Annotated[int, Strict()]

SourceType = Literal[
    "registry", "licence", "sro_inventory", "listing", "claim_registry", "vtu_research",
    "rental_inventory", "non_market_list", "chf_bc", "rezoning",
]
Role = Literal["owner", "interest_holder", "manager", "licensee"]
Sector = Literal["private", "non_profit", "government", "chinese_society"]


class _Model(BaseModel):
    model_config = ConfigDict(
        extra="forbid", json_schema_serialization_defaults_required=True
    )


class Source(_Model):
    type: SourceType
    as_of: IsoDate | None = None
    url: Text | None = None


class Party(_Model):
    role: Role
    name: Text
    entity_key: Text
    kind: None = None  # reserved for the sector project
    interest: Text | None = None
    pids: list[Text] = []
    same_as: Literal["owner", "manager"] | None = None
    sources: list[Source]


class Value(_Model):
    land: Int
    building: Int
    land_share: float = Field(ge=0, le=1)
    land_share_pctl: Int = Field(ge=0, le=100)


class Issues(_Model):
    count: Int = Field(ge=1)
    url: Text | None = None


class RegistrySearch(_Model):
    status: Literal["filed", "no_filing", "not_searched"]
    date: IsoDate | None = None


class Coop(_Model):
    status: Literal["open_waitlist", "closed"]
    ownership_model: Literal["non_profit", "equity"]
    url: Text | None = None


class Sro(_Model):
    rooms: Int | None = None
    occupancy: Literal["open", "closed"] | None = None
    owner_sector: Sector | None = None
    operator_sector: Sector | None = None


class Rezoning(_Model):
    status: Literal["approved", "rezoning", "upcoming"]
    category: Text
    detail: Text | None = None
    url: Text | None = None


class Building(_Model):
    id: Int
    origin: Literal["building", "overlay_sro", "overlay_coop"]
    address: Text
    name: Text | None
    also_known_as: list[Text]
    local_area: Text | None
    block_id: Int | None
    lat: float | None
    lon: float | None
    in_chinatown: bool
    in_village_plan: bool
    units: Int | None
    units_basis: Literal["inventory", "licence_fee", "sro_rooms"] | None
    year_built: Int | None
    listed_in: list[SourceType]
    value: Value | None
    issues: Issues | None
    parties: list[Party]
    network_id: Text | None
    registry_search: RegistrySearch
    coop: Coop | None
    sro: Sro | None
    rezoning: Rezoning | None


class Evidence(_Model):
    registry: Int
    vtu_research: Int


class NetworkTotals(_Model):
    buildings: Int
    units: Int
    open_issues: Int
    properties_on_title: Int | None


class Network(_Model):
    id: Text
    name: Text
    name_source: Literal["claim", "default"]
    tier: Literal["confirmed", "name_match"]
    evidence: Evidence
    entities: list[Text]
    totals: NetworkTotals


class BuildingRecordsFile(_Model):
    schema_version: Literal[2]
    records: dict[str, Building]


class NetworksFile(_Model):
    schema_version: Literal[2]
    networks: dict[str, Network]


class Contract(_Model):
    """Schema root only: one place the frontend's types are generated from."""

    building_records: BuildingRecordsFile
    networks: NetworksFile


def json_schema() -> dict:
    return Contract.model_json_schema(mode="serialization")
```

Note: the `Int` (strict) alias is what makes `year_built=1970.5`, `1970.0` and `"1970"` fail instead of being coerced; builders must pass real `int`s.

```python
"""The City's SRO inventory came out of a PDF. Text extraction split words
("N on-Profit"), and let a sector label spill into the neighbouring operator
cell together with a stray letter or two of the owner name ("vP rivate").
raw_sro keeps the text as published; this module reads it."""

from __future__ import annotations

import re

_SECTORS = {
    "private": "private",
    "nonprofit": "non_profit",
    "government": "government",
    "chinesesociety": "chinese_society",
}
# Letters of a neighbouring cell that may precede a spilled label.
_MAX_SPILL = 2


def _squash(text: object) -> str:
    return re.sub(r"[^a-z]", "", str(text).lower()) if text is not None else ""


def sector(text: object) -> str | None:
    """The sector a cell names, tolerating split words and a short spill."""
    squashed = _squash(text)
    for word, code in _SECTORS.items():
        if squashed.endswith(word) and len(squashed) - len(word) <= _MAX_SPILL:
            return code
    return None


def is_leaked_label(text: object) -> bool:
    """True when a name cell holds only a sector label (and spill), not a name."""
    return sector(text) is not None
```

```python
_INTERESTS = (

    """{addr_key: [{name, interest, pids}]} — who stands behind the reporting
    bodies on a building's PIDs. Public: name and interest type only. The
    query reads no residence, citizenship or address column, so none can
    reach an artifact from here."""
    keys_by_pid = pid_addr_keys(conn, pid_address_map_path)
    rows = conn.execute(
        "SELECT pid, reporting_body_name, type_of_interest, holder_name FROM raw_lotr_ownership "
        "WHERE holder_name IS NOT NULL AND TRIM(holder_name) != '' AND pid IS NOT NULL "
        "AND (data_fetch_status IS NULL OR data_fetch_status = 'SUCCESS')"
    ).fetchall()
    found: dict[str, dict[tuple[str, str], set[str]]] = defaultdict(lambda: defaultdict(set))
    spellings: dict[str, Counter] = defaultdict(Counter)
    for pid, body, type_of_interest, holder in rows:
        interest = _interest(type_of_interest)
        holder = holder.strip()
        if interest is None or sanitize_owner(holder) == sanitize_owner(body):
            continue
        key = sanitize_owner(holder)
        spellings[key][holder] += 1
        for addr_key in keys_by_pid.get(_normalize_pid(pid), ()):
            found[addr_key][(key, interest)].add(pid.strip())

    def display(key: str) -> str:
        counts = spellings[key]
        top = max(counts.values())
        return min(name for name, n in counts.items() if n == top)

    return {
        addr_key: [
            {"name": display(key), "interest": interest, "pids": sorted(pids)}
            for (key, interest), pids in sorted(
                holders.items(), key=lambda kv: (-len(kv[1]), display(kv[0][0]))
            )
        ]
        for addr_key, holders in found.items()
    }
```

```python
"""Each building's parties in their roles (spec 2026-10-08 §3).

Reads one reconstruct_points() row. Owners come from the registry, else the
SRO inventory or licence (already resolved into owner_* by export.py);
managers from listings, licence-held management and the SRO operator; the
licensee is always listed and linked (`same_as`) to the owner or manager it
turns out to be.
"""

from __future__ import annotations

import math
import re
from collections.abc import Mapping
from urllib.parse import urlparse

from .contract import Party, Source
from .normalize import sanitize_owner

_SUFFIXES = {"ltd", "limited", "inc", "incorporated", "corp", "corporation", "co", "company", "the"}
_OWNER_SOURCE = {"licence": "licence", "sro_list": "sro_inventory"}
_ISO_DATE = re.compile(r"^\d{4}-\d{2}-\d{2}")
_SENTINELS = {"(unknown)", "unknown"}


def _text(value: object) -> str | None:
    if value is None or (isinstance(value, float) and math.isnan(value)):
        return None
    s = str(value).strip()
    return None if not s or s.lower() in _SENTINELS else s


def _date(value: object) -> str | None:
    s = _text(value)
    return s[:10] if s and _ISO_DATE.match(s) else None


def _http(value: object) -> str | None:
    s = _text(value)
    return s if s and urlparse(s).scheme in ("http", "https") else None


def match_key(name: str) -> str:
    """Spelling-insensitive identity of an entity name: words without
    punctuation, corporate suffixes or a plural s ("Apts. Ltd." == "Apt Ltd")."""
    words = [w for w in re.findall(r"[a-z0-9]+", name.lower()) if w not in _SUFFIXES]
    return "".join(w[:-1] if len(w) > 3 and w.endswith("s") else w for w in words)


def _same(a: str, b: str, clusters: Mapping[str, str]) -> bool:
    if match_key(a) == match_key(b):
        return True
    ca, cb = clusters.get(a), clusters.get(b)
    return ca is not None and ca == cb


def _party(role: str, name: str, sources: list[Source], **kw) -> Party:
    return Party(role=role, name=name, entity_key=sanitize_owner(name), sources=sources, **kw)


def _owners(row: Mapping[str, object]) -> list[Party]:
    registry = row.get("registry_owner_pids") or []
    if registry:
        as_of = _date(row.get("registry_retrieved"))
        return [
            _party("owner", e["name"], [Source(type="registry", as_of=as_of)], pids=list(e["pids"]))
            for e in registry
        ]
    name = _text(row.get("owner_name"))
    source = _OWNER_SOURCE.get(_text(row.get("owner_source")) or "")
    return [_party("owner", name, [Source(type=source)])] if name and source else []


def _managers(row: Mapping[str, object], clusters: Mapping[str, str]) -> list[Party]:
    found: list[tuple[str, list[Source]]] = []

    def add(name: str | None, source: Source) -> None:
        if not name:
            return
        for known, sources in found:
            if _same(known, name, clusters):
                sources.append(source)
                return
        found.append((name, [source]))

    if _text(row.get("managed_by_source")) == "licence":
        add(_text(row.get("managed_by")), Source(type="licence"))
    listings = row.get("listings") or []
    managed = _text(row.get("managed_by"))
    # The known manager's own listing first, then any other company's.
    for listing in sorted(listings, key=lambda l: not (managed and _same(l["by"], managed, clusters))):
        add(_text(listing.get("by")), Source(
            type="listing", as_of=_date(listing.get("seen")), url=_http(listing.get("url"))
        ))
    add(_text(row.get("sro_operator")), Source(type="sro_inventory"))
    return [_party("manager", name, sources) for name, sources in found]


def build_parties(row: Mapping[str, object], clusters: Mapping[str, str]) -> list[Party]:
    owners = _owners(row)
    holders = [
        _party("interest_holder", h["name"], [Source(type="registry", as_of=_date(row.get("registry_retrieved")))],
               interest=h["interest"], pids=list(h["pids"]))
        for h in (row.get("interest_holders") or [])
    ]
    managers = _managers(row, clusters)
    parties = [*owners, *holders, *managers]
    licence = _text(row.get("licence_holder"))
    if licence:
        same_as = None
        for role, group in (("owner", owners), ("manager", managers)):
            match = next((p for p in group if _same(p.name, licence, clusters)), None)
            if match:
                same_as = role
                if not any(s.type == "licence" for s in match.sources):
                    match.sources.append(Source(type="licence"))
                break
        parties.append(_party("licensee", licence, [Source(type="licence")], same_as=same_as))
    return parties
```

```python
"""reconstruct_points() rows -> contract v2 records (spec 2026-10-08 §2, §4)."""

from __future__ import annotations

import bisect
import math
from collections.abc import Iterable, Mapping
from statistics import median

from .contract import (
    Building, Coop, Evidence, Issues, Network, NetworkTotals, RegistrySearch, Rezoning, Sro, Value,
)
from .export_parties import _date, _http, _text, build_parties
from .sro_text import sector

_LISTED_IN = {
    "rental inventory": "rental_inventory",
    "non-market housing list": "non_market_list",
    "rental licence": "licence",
    "manager listing": "listing",
}


def _num(value: object) -> float | None:
    if value is None or (isinstance(value, float) and math.isnan(value)):
        return None
    return float(value)


def _int(value: object) -> int | None:
    n = _num(value)
    return None if n is None else int(round(n))


def land_share(row: Mapping[str, object]) -> float | None:
    land, bldg = _num(row.get("value_land")), _num(row.get("value_bldg"))
    if land is None or bldg is None or land + bldg <= 0:
        return None
    return land / (land + bldg)


class LandShares:
    """Every building's land share, for percentiles against the city."""

    def __init__(self, shares: list[float]):
        self._sorted = sorted(shares)

    def percentile(self, share: float) -> int:
        """Whole percent of buildings with a strictly lower land share."""
        return int(round(100 * bisect.bisect_left(self._sorted, share) / len(self._sorted)))

    @property
    def median(self) -> float | None:
        return median(self._sorted) if self._sorted else None


def _value(row, shares: LandShares) -> Value | None:
    share = land_share(row)
    if share is None:
        return None
    return Value(land=_int(row["value_land"]), building=_int(row["value_bldg"]),
                 land_share=share, land_share_pctl=shares.percentile(share))


def _units_basis(row) -> str | None:
    if _int(row.get("units")) is None:
        return None
    if row.get("building_source") == "rental licence":
        return "sro_rooms" if row.get("is_sro") else "licence_fee"
    return "inventory"


def _listed_in(row) -> list[str]:
    out = []
    first = _LISTED_IN.get(row.get("building_source") or "")
    if first:
        out.append(first)
    for flag, source in (("is_sro", "sro_inventory"), ("is_coop", "chf_bc"), ("is_rezoning", "rezoning")):
        if row.get(flag) and source not in out:
            out.append(source)
    return out


def _lower(value: object) -> str | None:
    s = _text(value)
    return s.lower() if s else None


def _coop(row) -> Coop | None:
    if not row.get("is_coop"):
        return None
    return Coop(status=_text(row["coop_status"]), ownership_model=_text(row["coop_ownership_model"]),
                url=_http(row.get("coop_url")))


def _sro(row) -> Sro | None:
    if not row.get("is_sro"):
        return None
    rooms = _text(row.get("sro_registered_rooms"))
    return Sro(
        rooms=int(rooms) if rooms and rooms.isdigit() else None,
        occupancy=_lower(row.get("sro_occupancy_status")),
        owner_sector=sector(row.get("sro_ownership_group")),
        operator_sector=sector(row.get("sro_operator_group")),
    )


def _rezoning(row) -> Rezoning | None:
    if not row.get("is_rezoning"):
        return None
    return Rezoning(status=_lower(row["rezoning_status"]), category=_text(row["rezoning_category"]),
                    detail=_text(row.get("rezoning_status_detail")), url=_http(row.get("rezoning_link")))


def _registry_search(row) -> RegistrySearch:
    if row.get("registry_owner_pids"):
        return RegistrySearch(status="filed")
    searched = _date(row.get("registry_no_filing"))
    return RegistrySearch(status="no_filing", date=searched) if searched else RegistrySearch(status="not_searched")


def _issues(row) -> Issues | None:
    count = _int(row.get("n_issues"))
    return Issues(count=count, url=_http(row.get("issues_details"))) if count else None


def _coord(value: object) -> float | None:
    n = _num(value)
    return None if n is None else round(n, 6)


def build_building(row: Mapping[str, object], *, shares: LandShares, clusters: Mapping[str, str]) -> Building:
    return Building(
        id=int(row["b_id"]),
        origin=row.get("source") or "building",
        address=_text(row["address"]),
        name=_text(row.get("building_name")),
        also_known_as=[n for n in (_text(v) for v in (row.get("other_names") or [])) if n],
        local_area=_text(row.get("local_area")),
        block_id=_int(row.get("block_id")),
        lat=_coord(row.get("lat")),
        lon=_coord(row.get("lon")),
        in_chinatown=bool(row.get("in_chinatown")),
        in_village_plan=bool(row.get("in_village_plan")),
        units=_int(row.get("units")),
        units_basis=_units_basis(row),
        year_built=_int(row.get("year_built")),
        listed_in=_listed_in(row),
        value=_value(row, shares),
        issues=_issues(row),
        parties=build_parties(row, clusters),
        network_id=_text(row.get("network_key")),
        registry_search=_registry_search(row),
        coop=_coop(row),
        sro=_sro(row),
        rezoning=_rezoning(row),
    )


def build_networks(rows: Iterable[Mapping[str, object]]) -> dict[str, Network]:
    """One record per network key on the map: claims networks are
    `confirmed`; every other grouping (licence name, SRO owner, an owner on
    its own) is a `name_match`."""
    networks: dict[str, Network] = {}
    for key, rows in _group_rows(rows).items():
        first = rows[0]
        claims = first.get("network_source") == "claims"
        evidence = first.get("network_evidence") or {}
        networks[key] = Network(
            id=key,
            name=_text(first["network_name"]),
            name_source="claim" if first.get("network_name_source") == "claim" else "default",
            tier="confirmed" if claims else "name_match",
            evidence=Evidence(registry=int(evidence.get("registry", 0)),
                              vtu_research=int(evidence.get("vtu_research", 0))),
            entities=[e for e in (_text(v) for v in (first.get("network_entities") or [])) if e],
            totals=NetworkTotals(
                buildings=len(rows),
                units=sum(_int(r.get("units")) or 0 for r in rows),
                open_issues=sum(_int(r.get("n_issues")) or 0 for r in rows),
                properties_on_title=_int(first.get("network_properties_on_title")) if claims else None,
            ),
        )
    return networks


def _group_rows(rows: Iterable[Mapping[str, object]]) -> dict[str, list[Mapping[str, object]]]:
    groups: dict[str, list[Mapping[str, object]]] = {}
    for r in rows:
        key = _text(r.get("network_key"))
        if key:
            groups.setdefault(key, []).append(r)
    return groups
```

```ts
 * The flat view model the sidebar tables, landlord picker, map indexes,

 */
import type { Building, Network, Party } from './contract.gen';
import type { BuildingRecord } from './types';

const OWNER_SOURCE: Record<string, string> = { registry: 'registry', licence: 'licence', sro_inventory: 'sro_list' };

export const FLAT_COLUMNS = [
  'b_id', 'source', 'address', 'building_name', 'local_area', 'block_id', 'units', 'year_built',
  'owner_name', 'owner_key', 'owner_source', 'licence_holder', 'managed_by',

  'housing_type', 'rezoning_status', 'n_issues', 'issues_details',
  'in_chinatown', 'in_village_plan', 'lat', 'lon',
];

const first = (b: Building, role: Party['role']): Party | null => b.parties.find((p) => p.role === role) ?? null;

export function flatten(b: Building, networks: Record<string, Network>): BuildingRecord {
  const owner = first(b, 'owner');
  const net = b.network_id ? networks[b.network_id] ?? null : null;
  const housing = [b.coop ? 'co-op' : '', b.sro ? 'sro' : ''].filter(Boolean).join(', ');
  return {
    b_id: b.id,
    source: b.origin,
    address: b.address,
    building_name: b.name,
    other_names: b.also_known_as,
    local_area: b.local_area,
    block_id: b.block_id,
    units: b.units,
    year_built: b.year_built,
    owner_name: owner?.name ?? null,
    owner_key: owner?.entity_key ?? null,
    owner_source: owner ? OWNER_SOURCE[owner.sources[0]?.type ?? ''] ?? null : null,
    licence_holder: first(b, 'licensee')?.name ?? null,
    managed_by: first(b, 'manager')?.name ?? null,
    network_key: net?.id ?? null,
    network_name: net?.name ?? null,

    network_name_source: net?.name_source ?? null,
    network_entities: net?.entities ?? null,
    network_evidence: net ? net.evidence : null,
    network_evidence_registry: net ? net.evidence.registry : null,

    network_buildings_on_map: net?.totals.buildings ?? null,
    registry_no_filing: b.registry_search.status === 'no_filing' ? b.registry_search.date : null,
    value_land: b.value?.land ?? null,
    value_bldg: b.value?.building ?? null,
    bldg_land_ratio: b.value && b.value.land > 0 ? b.value.building / b.value.land : null,

    rezoning_status: b.rezoning?.status ?? null,
    n_issues: b.issues?.count ?? null,
    issues_details: b.issues?.url ?? null,

    in_village_plan: b.in_village_plan,
```

```ts
/** The URL if it is http(s), else null — never link javascript: or other schemes. */
export function safeUrl(v: unknown): string | null {
  if (typeof v !== 'string') return null;
  try {
    const u = new URL(v);
    return u.protocol === 'http:' || u.protocol === 'https:' ? u.href : null;
  } catch {
    return null;
  }
}

export function formatCurrencyCompact(v: number): string {
  if (v >= 1e6) return `$${(v / 1e6).toFixed(1)}M`;
  if (v >= 1e3) return `$${Math.round(v / 1e3).toLocaleString('en-US')}K`;
  return `$${Math.round(v)}`;
}

export const plural = (n: number, one: string, many: string): string => `${n.toLocaleString('en-US')} ${n === 1 ? one : many}`;

export function linked(text: string, url: string | null | undefined): string {
  const href = safeUrl(url);
  return href ? `<a href="${escapeHtml(href)}" target="_blank" rel="noopener">${escapeHtml(text)} ↗</a>` : escapeHtml(text);
}

const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
/** "2026-09-30" -> "Sep 2026". */
export const monthYear = (iso: string): string => `${MONTHS[Number(iso.slice(5, 7)) - 1]} ${iso.slice(0, 4)}`;

/** Public provenance text for one source: types and dates only. */
export function sourceText(s: Source, licenceYear: number | null): string {
  switch (s.type) {
    case 'registry': return s.as_of ? `BC Land Owner Transparency Registry, record retrieved ${s.as_of}` : 'BC Land Owner Transparency Registry';
    case 'licence': return licenceProvenance(licenceYear);
    case 'sro_inventory': return SRO_INVENTORY;
    case 'listing': return listingProvenance(s.as_of ?? '');
    case 'vtu_research': return 'VTU research';
    case 'claim_registry': return 'Provincial registry filing';
    case 'rental_inventory': return 'City of Vancouver rental inventory (FOI)';
    case 'non_market_list': return 'City of Vancouver non-market housing list';
    case 'chf_bc': return 'Co-operative Housing Federation of BC';
    case 'rezoning': return 'City of Vancouver rezoning applications';
  }
}
```

```ts
/**
 * The building popup (spec 2026-10-08 §6): one header, three tabs. Leaflet
 * takes the popup as an HTML string, so tab switching is delegated from the
 * document (initPopupTabs) rather than bound per popup. The last tab opened
 * is remembered in memory for the page session, so an organizer clicking
 * through buildings stays on Ownership; a reload starts on Summary.
 */
import type { Building, Network } from '../contract.gen';
import { formatAddress } from '../address';
import { escapeHtml } from '../html';
import { renderBuilding } from './building';
import { renderOwnership } from './ownership';
import { renderSummary } from './summary';

export type TabId = 'summary' | 'ownership' | 'building';
const TABS: [TabId, string][] = [['summary', 'Summary'], ['ownership', 'Ownership'], ['building', 'Building']];

export interface PopupContext {
  networks: Record<string, Network>;
  licenceYear: number | null;
  landShareMedian: number | null;
}

let remembered: TabId = 'summary';
export const currentTab = (): TabId => remembered;
export const resetTabMemory = (): void => { remembered = 'summary'; };

function header(b: Building): string {
  const units = b.units === null ? '' : `${b.units.toLocaleString('en-US')} ${b.sro && b.units_basis !== 'licence_fee' ? 'rooms' : 'units'}`;
  const sub = [b.name ?? '', b.local_area ?? '', units, b.year_built === null ? '' : `built ${b.year_built}`]
    .filter(Boolean).join(' · ');
  return `<div class="popup-address">${escapeHtml(formatAddress(b.address))}</div>` +
    (sub ? `<div class="popup-sub">${escapeHtml(sub)}</div>` : '');
}

export function renderPopup(b: Building, ctx: PopupContext): string {
  const panels: Record<TabId, string> = {
    summary: renderSummary(b, ctx), ownership: renderOwnership(b, ctx), building: renderBuilding(b, ctx),
  };
  const tabs = TABS.map(([id, label]) => {
    const on = id === remembered;
    return `<button type="button" role="tab" class="tc-tab" data-tab="${id}" id="tc-tab-${id}" ` +
      `aria-controls="tc-panel-${id}" aria-selected="${on}" tabindex="${on ? 0 : -1}">${label}</button>`;
  }).join('');
  const bodies = TABS.map(([id]) =>
    `<div role="tabpanel" class="tc-panel" id="tc-panel-${id}" aria-labelledby="tc-tab-${id}"${id === remembered ? '' : ' hidden'}>${panels[id]}</div>`,
  ).join('');
  return `<div class="tc-popup">${header(b)}<div role="tablist" class="tc-tabs">${tabs}</div>${bodies}</div>`;
}

function select(popup: Element, id: TabId, focus: boolean): void {
  remembered = id;
  popup.querySelectorAll<HTMLElement>('.tc-tab').forEach((t) => {
    const on = t.dataset.tab === id;
    t.setAttribute('aria-selected', String(on));
    t.tabIndex = on ? 0 : -1;
    if (on && focus) t.focus();
  });
  popup.querySelectorAll<HTMLElement>('.tc-panel').forEach((p) => { p.hidden = p.id !== `tc-panel-${id}`; });
}

const initialized = new WeakSet<Document>();

export function initPopupTabs(doc: Document): void {
  if (initialized.has(doc)) return;  // one set of delegated listeners per document
  initialized.add(doc);
  doc.addEventListener('click', (e) => {
    const tab = (e.target as Element | null)?.closest?.('.tc-tab') as HTMLElement | null;
    const popup = tab?.closest('.tc-popup');
    if (tab && popup) select(popup, tab.dataset.tab as TabId, false);
  });
  doc.addEventListener('keydown', (e) => {
    const tab = (e.target as Element | null)?.closest?.('.tc-tab') as HTMLElement | null;
    const popup = tab?.closest('.tc-popup');
    if (!tab || !popup || (e.key !== 'ArrowRight' && e.key !== 'ArrowLeft')) return;
    const ids = TABS.map(([id]) => id);
    const step = e.key === 'ArrowRight' ? 1 : -1;
    const next = ids[(ids.indexOf(tab.dataset.tab as TabId) + step + ids.length) % ids.length];
    e.preventDefault();
    select(popup, next, true);
  });
}
```

```ts
/** Summary tab — the tenant's first look (spec 2026-10-08 §6). */
import type { Building, Party } from '../contract.gen';
import { escapeHtml } from '../html';
import { provenanceIcon } from '../provenance';
import { LABELS } from './labels';
import { linked, plural, sourceText } from './format';
import type { PopupContext } from './index';

const NOT_ON_RECORD = '<span class="popup-muted">Not on record</span>';
const row = (k: string, v: string) => `<div class="popup-row"><span class="popup-k">${k}</span> <span>${v}</span></div>`;
const tier = (label: string, weak = false) => ` <span class="popup-tier${weak ? ' weak' : ''}">${escapeHtml(label)}</span>`;
const icon = (p: Party, ctx: PopupContext) => provenanceIcon(p.sources.map((s) => sourceText(s, ctx.licenceYear)).join('; '));
const first = (b: Building, role: Party['role']) => b.parties.find((p) => p.role === role) ?? null;

function badges(b: Building): string {
  const out: string[] = [];
  if (b.sro) {
    out.push('SRO');
    if (b.sro.occupancy) out.push(LABELS.occupancy[b.sro.occupancy]);
  }
  if (b.coop) out.push('Co-op');
  return out.length ? `<div class="popup-badges">${out.map((t) => `<span class="popup-badge">${escapeHtml(t)}</span>`).join('')}</div>` : '';
}

function ownedBy(b: Building, ctx: PopupContext): string {
  const net = b.network_id ? ctx.networks[b.network_id] : undefined;
  if (net && net.tier === 'confirmed') {
    const ev = `Grouped from ${net.evidence.registry} registry filings and ${net.evidence.vtu_research} VTU research claims.`;
    return `<strong>${escapeHtml(net.name)}</strong>${tier('confirmed')}${provenanceIcon(ev)}`;
  }
  const owner = first(b, 'owner');
  if (!owner) return NOT_ON_RECORD;
  const licenceOnly = owner.sources.every((s) => s.type === 'licence');
  return `<strong>${escapeHtml(owner.name)}</strong>${licenceOnly ? tier('licence only', true) : ''}${icon(owner, ctx)}`;
}

function managedBy(b: Building, ctx: PopupContext): string {
  const m = first(b, 'manager');
  if (!m) return NOT_ON_RECORD;
  const url = m.sources.find((s) => s.type === 'listing' && s.url)?.url ?? null;
  return `<strong>${linked(m.name, url)}</strong>${icon(m, ctx)}`;
}

function portfolio(b: Building, ctx: PopupContext): string {
  const net = b.network_id ? ctx.networks[b.network_id] : undefined;
  if (!net) return '';
  if (net.totals.buildings <= 1) return `<div class="popup-muted">Only building we know of for this owner</div>`;
  return `<div class="popup-muted">${escapeHtml(`${net.name} holds ${plural(net.totals.buildings, 'building', 'buildings')} · ${plural(net.totals.units, 'unit', 'units')} on the map`)}</div>`;
}

function rezoningAlert(b: Building): string {
  const z = b.rezoning;
  if (!z || (z.status !== 'approved' && z.status !== 'rezoning')) return '';
  const when = z.detail ? ` (${escapeHtml(z.detail.replace(/^Approved\s+/, ''))})` : '';
  const link = z.url ? ` · ${linked('Shape Your City', z.url)}` : '';
  return `<div class="popup-alert"><strong>${escapeHtml(LABELS.rezoning[z.status])}</strong>${when} — the site may be redeveloped${link}</div>`;
}

export function renderSummary(b: Building, ctx: PopupContext): string {
  const licensee = first(b, 'licensee');
  const licensed = licensee && licensee.same_as === null
    ? row('Licensed to', `${escapeHtml(licensee.name)}${icon(licensee, ctx)}`) : '';
  const issues = b.issues
    ? `<div class="popup-issues">${linked(plural(b.issues.count, 'outstanding City issue', 'outstanding City issues'), b.issues.url)}</div>` : '';
  return badges(b) + rezoningAlert(b) + row('Owned by', ownedBy(b, ctx)) + row('Managed by', managedBy(b, ctx)) +
    licensed + portfolio(b, ctx) + issues;
}
```

```ts
/** Ownership tab — the organizer's chain: network → on title → this building (spec 2026-10-08 §6). */
import type { Building, Party } from '../contract.gen';
import { escapeHtml } from '../html';
import { provenanceIcon } from '../provenance';
import { LABELS } from './labels';
import { linked, monthYear, plural, sourceText } from './format';
import type { PopupContext } from './index';

const roles = (b: Building, role: Party['role']) => b.parties.filter((p) => p.role === role);
const icon = (p: Party, ctx: PopupContext) => provenanceIcon(p.sources.map((s) => sourceText(s, ctx.licenceYear)).join('; '));
const muted = (html: string) => `<div class="popup-muted">${html}</div>`;
const node = (cls: string, role: string, body: string) =>
  `<div class="node ${cls}"><div class="role">${role}</div>${body}</div>`;
const collapsed = (label: string, items: string[]) =>
  items.length ? `<details><summary>${escapeHtml(label)}</summary><ul>${items.map((i) => `<li>${i}</li>`).join('')}</ul></details>` : '';

function networkNode(b: Building, ctx: PopupContext): string {
  const net = b.network_id ? ctx.networks[b.network_id] : undefined;
  if (!net || (net.tier !== 'confirmed' && net.totals.buildings <= 1)) return '';
  const weak = net.tier !== 'confirmed';
  const evidence = weak ? 'Grouped by the same owner name'
    : `${net.evidence.registry} registry filings + ${net.evidence.vtu_research} VTU research claims`;
  const t = net.totals;
  const card = `<div class="popup-stats">` +
    `<div><b>${t.buildings}</b><span>buildings</span></div>` +
    `<div><b>${t.units.toLocaleString('en-US')}</b><span>units</span></div>` +
    `<div><b class="popup-issue-num">${t.open_issues}</b><span>open issues</span></div></div>`;
  return node('net', 'Network',
    `<strong>${escapeHtml(net.name)}</strong> <span class="popup-tier${weak ? ' weak' : ''}">${escapeHtml(LABELS.tier[net.tier])}</span>` +
    muted(escapeHtml(evidence)) + card +
    collapsed(plural(net.entities.length, 'linked entity', 'linked entities'), net.entities.map(escapeHtml)));
}

function registryLine(p: Party): string {
  const reg = p.sources.find((s) => s.type === 'registry');
  const pids = p.pids.length ? `${p.pids.length === 1 ? 'PID' : 'PIDs'} ${p.pids.join(', ')}` : '';
  const when = reg?.as_of ? `registry, ${monthYear(reg.as_of)}` : '';
  const line = [pids, when].filter(Boolean).join(' · ');
  return line ? muted(escapeHtml(line)) : '';
}

function ownersBody(owners: Party[], ctx: PopupContext): string {
  if (owners.length <= 1) {
    const [o] = owners;
    return `<strong>${escapeHtml(o.name)}</strong>${icon(o, ctx)}${registryLine(o)}`;
  }
  const samePids = owners.every((o) => o.pids.join() === owners[0].pids.join());
  if (samePids) {
    const names = owners.map((o) => o.name);
    const joined = `${names.slice(0, -1).join(', ')} and ${names[names.length - 1]}`;
    return `Jointly owned by <strong>${escapeHtml(joined)}</strong>${icon(owners[0], ctx)}${registryLine(owners[0])}`;
  }
  return owners.map((o) => `<div><strong>${escapeHtml(o.name)}</strong> ${escapeHtml(`(${o.pids.length === 1 ? 'PID' : 'PIDs'} ${o.pids.join(', ')})`)}${icon(o, ctx)}</div>`).join('');
}

function licenceLine(b: Building, role: 'owner' | 'manager', shownName: string, ctx: PopupContext): string {
  const lic = roles(b, 'licensee')[0];
  if (!lic || lic.same_as !== role || lic.name === shownName) return '';
  return muted(`Licensed as ${escapeHtml(lic.name)}${icon(lic, ctx)}`);
}

function titleNode(b: Building, ctx: PopupContext): string {
  const owners = roles(b, 'owner');
  const searched = b.registry_search.status === 'no_filing' && b.registry_search.date
    ? muted(escapeHtml(`No filing in the land title registry (searched ${b.registry_search.date})`)) : '';
  if (!owners.length) return node('', 'On title', `<span class="popup-muted">Not on record</span>${searched}`);
  const holders = roles(b, 'interest_holder').map((h) => escapeHtml(`${h.name}${h.interest ? ` (${h.interest})` : ''}`));
  return node('', 'On title', ownersBody(owners, ctx) + licenceLine(b, 'owner', owners[0].name, ctx) + searched +
    collapsed(plural(holders.length, 'interest holder', 'interest holders'), holders));
}

function managerAside(b: Building, ctx: PopupContext): string {
  const managers = roles(b, 'manager');
  const lic = roles(b, 'licensee')[0];
  const unmatched = lic && lic.same_as === null
    ? `<div>Licensed to ${escapeHtml(lic.name)}${icon(lic, ctx)}</div>` : '';
  const items = managers.map((m) => {
    const listing = m.sources.find((s) => s.type === 'listing');
    const seen = listing?.as_of ? muted(escapeHtml(`company website, seen ${monthYear(listing.as_of)}`)) : '';
    return `<div><strong>${linked(m.name, listing?.url ?? null)}</strong>${icon(m, ctx)}${seen}${licenceLine(b, 'manager', m.name, ctx)}</div>`;
  }).join('');
  if (!items && !unmatched) return '';
  return `<div class="popup-aside">${items ? `<div class="role">Manages</div>${items}` : ''}${unmatched}</div>`;
}

    node('bldg', 'This building', `<span class="popup-muted">${escapeHtml(b.address)}</span>`);
  return `<div class="chain">${chain}</div>${managerAside(b, ctx)}`;
}
```

```ts
/** Building tab — value and redevelopment pressure, civic records (spec 2026-10-08 §6). */
import type { Building } from '../contract.gen';
import { escapeHtml } from '../html';
import { provenanceIcon } from '../provenance';
import { LABELS } from './labels';
import { formatCurrencyCompact, linked, sourceText } from './format';
import type { PopupContext } from './index';

const section = (title: string, body: string) => `<div class="popup-lbl">${title}</div>${body}`;
const row = (k: string, v: string) => `<div class="popup-row"><span class="popup-k">${k}</span> <span>${v}</span></div>`;
const LAND_SHARE_NOTE =
  'Share of the assessed value that is land. Where land is worth far more than the building on it, ' +
  'redeveloping the site pays more than keeping the building — a sign of redevelopment pressure.';

function value(b: Building, ctx: PopupContext): string {
  const v = b.value;
  if (!v) return '';
  const pct = Math.round(v.land_share * 1000) / 10;
  const median = ctx.landShareMedian === null ? ''
    : `<div class="median" style="left:${Math.round(ctx.landShareMedian * 100)}%"></div>`;
  const label = ctx.landShareMedian === null ? ''
    : `<div class="median-row"><span class="median-label" style="left:${Math.round(ctx.landShareMedian * 100)}%">city median</span></div>`;
  return section('Assessed value',
    `<div class="value-bar"><div class="fill" style="width:${pct}%"></div>${median}</div>${label}` +
    `<div class="popup-muted">Land <b>${formatCurrencyCompact(v.land)}</b> (${Math.round(v.land_share * 100)}%) · ` +
    `Building <b>${formatCurrencyCompact(v.building)}</b>${provenanceIcon(LAND_SHARE_NOTE)}</div>` +
    `<div class="popup-muted">${escapeHtml(`Land share higher than ${v.land_share_pctl}% of rental buildings on the map`)}</div>`);
}

const MONTH = /^(?:Approved\s+)?([A-Z][a-z]+)\w*\s+(\d{1,2}),\s+(\d{4})$/;
function rezoning(b: Building): string {
  const z = b.rezoning;
  if (!z) return '';
  const m = z.detail?.match(MONTH);
  const when = m ? ` · ${m[1].slice(0, 3)} ${m[2]}, ${m[3]}` : z.detail && z.detail !== 'Application in Process' ? ` · ${z.detail}` : '';
  const status = { approved: 'Approved', rezoning: 'In progress', upcoming: 'Upcoming' }[z.status];
  return section('Rezoning',
    row('Status', escapeHtml(status + when)) + row('Type', escapeHtml(LABELS.rezoningCategory(z.category))) +
    (z.url ? row('Details', linked('Shape Your City', z.url)) : ''));
}

function sro(b: Building): string {
  const s = b.sro;
  if (!s) return '';
  const sectors = [s.owner_sector && `${LABELS.sector[s.owner_sector]} owner`, s.operator_sector && `${LABELS.sector[s.operator_sector]} operator`]
    .filter(Boolean).join(' · ');
  const cap = (t: string) => t.charAt(0).toUpperCase() + t.slice(1);
  return section('SRO',
    (s.rooms !== null ? row('Rooms', `${s.rooms} registered`) : '') +
    (s.occupancy ? row('Status', LABELS.occupancy[s.occupancy]) : '') +
    (sectors ? row('Sectors', escapeHtml(cap(sectors))) : ''));
}

function coop(b: Building): string {
  const c = b.coop;
  if (!c) return '';
  return section('Co-op',
    row('Model', LABELS.coopModel[c.ownership_model]) + row('Waitlist', LABELS.coopStatus[c.status].replace('Waitlist ', '')) +
    (c.url ? row('More', linked('CHF BC listing', c.url)) : ''));
}

export function renderBuilding(b: Building, ctx: PopupContext): string {
  const aka = b.also_known_as.length ? `<div class="popup-muted">${escapeHtml(`Also known as ${b.also_known_as.join(', ')}`)}</div>` : '';
  const issues = b.issues
    ? section('City issues', `<div class="popup-issues">${linked(`${b.issues.count.toLocaleString('en-US')} outstanding · details`, b.issues.url)}</div>`)
    : '';
  const listed = b.listed_in.map((s) => sourceText({ type: s, as_of: null, url: null }, ctx.licenceYear)).join(' · ');
  const records = listed ? section('Records', `<div class="popup-muted">${escapeHtml(`Listed in ${listed}`)}</div>`) : '';
  return aka + value(b, ctx) + rezoning(b) + sro(b) + coop(b) + issues + records;
}
```
